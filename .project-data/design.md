# PureGantt Design

PureGantt builds interactive Frappe Gantt project timelines with dependencies, progress, and `.gantt` packages.

The app should focus on clear project scheduling: task rows, dependencies, progress, date ranges, package loading, and exportable timeline state. Gantt document modeling, path handling, samples, and bootstrapping stay inside the app.

The current assistant surface is intentionally small. Future assistant work should add tools only when they map to real timeline actions such as inspecting tasks, adjusting dependencies, or updating schedule metadata.
